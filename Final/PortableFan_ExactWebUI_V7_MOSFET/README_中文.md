# PortableFan V7 — Original driver single-key MOSFET bridge + Final Web UI

基于用户最终 React 项目移植的 240×240 Web Canvas 画面，以及此前已在 V2 CO5300 点亮的 TCA9554 + Waveshare BSP。完整项目以此 ZIP 为准。

## 重点：单键驱动板不支持真正的零延迟 BOOST

- 原驱动板只有一根 KEY：双击启动、短按三档循环、长按关机；关机按住进入临时最高档。
- **不应在原驱动板运行状态直接把 KEY 长时间按住作为 B 的 BOOST**：那会触发关机。
- 因此本工程通过 MOSFET 重现原按钮：A 长按发“双击”，A 短按发“短按”，A 长按关机时发“长按”。B 按住时，后台发若干短按切至第三档，松开后再发若干短按回之前基础档。
- 这不是瞬间切换。物理风速可能滞后数百毫秒至数秒，软件状态/屏幕会立刻变。真正即时 BOOST 应改造驱动芯片的 PWM/档位接口，或更换可直接控制的驱动板。
- 原驱动板默认开机档位不明。如果双击启动不是 ECO，则调 `FAN_DRIVER_START_MODE`（0=ECO，1=NORMAL，2=HIGH）。电路板在 ESP 重启时可能已在运行，软件预测状态会失步。测试前要先确保原板处于 OFF。

## 引脚（原型方案，务必核对你手上 V2 的实物丝印）

| 功能 | GPIO | 接法 |
|------|------|------|
| A 实体按钮 | GPIO0 (BOOT) | 两端分别接 GPIO0 与 ESP GND（并联于原板 BOOT 键）|
| B 实体按钮 | GPIO16 | 两端分别接 GPIO16 与 ESP GND；不要开启 I2S 音频 |
| MOSFET Gate | GPIO18 | 通过 1k 电阻连接 G；G 再用 100k 电阻接 S/GND |
| 电池检测 | GPIO17 (ADC2_CH6) | BMS P+ → 100k → ADC GPIO17；GPIO17 → 47k → BMS P−；建议 100nF 到 GND |

**GPIO0 是 BOOT 启动配置脚，不宜用于量产产品的主电源按钮。** 按住 A 并同时给 ESP32 上电/复位，会触发下载模式，无法正常开机。原型测试可以如此用；正式产品应更换引脚分配（例如独立 I²C GPIO 扩展器/外部 ADC）。该引脚方案不是量产设计。

## MOSFET 接线（原按钮两端先测量）

选 AO3400A 等有 VGS=2.5V 导通规格的 N 沟道 MOSFET，**它只模拟轻触按钮，不承载电机电流！** 核对实际封装的 G/D/S 引脚，不要按图形随意猜脚位。

```
ESP32 GPIO18 --- 1kΩ --- [G] N-MOSFET [D] ---- 驱动板 KEY (松开时对驱动地约5V)
                             |       [S] ---- 驱动板 KEY_GND / GND
                            100kΩ     |
                             |        |
ESP32 GND -------------------+--------+---- 驱动板 GND (验证后共地)
```

仅当原按钮 KEY 是“上拉 5V、按下短接到地”的 **低侧按键** 时，上述接法才成立。

**必须先测：** 驱动供电正常、按钮松开时分别测两焊盘对驱动板 GND，一个约 5V，一个约 0V；按下后两个应接近 0V。用户之前量到“两端差 5V”本身不够确定接法。确认 GND 能安全共地；否则应使用光耦 / PhotoMOS 隔离，在原按钮两端模拟干接点，不要直接共地。

不要将 5V KEY 直接接 ESP32 GPIO。不要将 2S 8.4V 电池接 ESP32 的 3.7V 电池口。电机的驱动、保护板、充电电路继续使用原厂电路。

## 固件交互

- A 短按，风扇关机：仅屏幕唤醒，不开电机。
- A 长按，风扇关机：设置风扇开启，控制桥向旧板模拟双击，回到 ECO 或 NORMAL 基础档。
- A 短按，运行：基础档 ECO↔NORMAL 循环。
- A 长按，运行：风扇关机，控制桥模拟旧板长按。
- B 按住且风扇运行：临时目标 HIGH/BOOST；松开后目标恢复基础档。
- B 按住且风扇关闭：无启动效果（可唤醒屏幕）。
- 小尺寸原始像素数字（旧开度位置）改为 **01=ECO、02=NORMAL、03=BOOST**；默认保留原图形、数字大小和布局，`FAN_UI_MODE_DIGITS=0` 则锁定显示旧 01。
- 屏幕轻触：唤醒，不改变风扇运行状态。
- 任意输入后60秒没有操作：亮度设 0，显示熄灭，但屏幕触摸仍在工作，风扇**不停止**。

## 安全默认值和调试步骤

`main/fan_board_config.h` 内 `FAN_ENABLE_MOSFET_KEY` 初始为 `0`，所以刚烧录**不会向旧驱动板发控制脉冲**。先验证 A/B 和触摸的串口日志。确认旧按钮测量、GND、安全接线、旧板在 OFF 状态、MOSFET G/D/S 丝印之后，改成 `1` 再编译并逐步测试。

如果你接过上一次 ADC 电路，确认 GPIO17 仍只做 ADC。`FAN_BUTTON_A_GPIO=0` 属于 BOOT，请勿用按住 A 的方式执行冷启动。启动日志会标示 MOSFET 是否已启用。

## ESP-IDF 编译

VS Code 打开工程根目录，ESP-IDF v5.5.6：

```powershell
$env:IDF_TARGET = "esp32s3"
idf.py set-target esp32s3
idf.py build
idf.py -p COM5 flash monitor
```

一个重要限制：当前只是软件的预测档位，没有电机转速反馈；原板长按阈值、双击间隔、初始档位需要用实际板测试调整。源码依然附带 `web_reference/` 和原网页素材用于 UI 校对。没有在用户设备上运行或通过完整 ESP-IDF 编译验证。
